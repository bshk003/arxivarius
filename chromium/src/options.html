Available Tags:
%a full author(s)' name(s) in the order of appearance
%A author(s)' name(s) in the initials format
%f the full first author's name
%F the first author's name in the initials format
%i arXiv publication ID
%s the primary subject
%t the title
%Y, %M, %D the publication date (year, month, day)
%% the percent sign

The forward slashes (/), when present, specify a path relative to the downloads directory.
